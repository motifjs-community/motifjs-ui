# Showcase: an order screen

> Get started · @motifx-community/ui 0.1.0-beta.10

An order entry screen built with the kit, structured the way a MotifJS application is normally built: state and operations live in a model (`OrderModel`), and the page binds to it. The customer list is a data source of 5,000 rows that responds like a server.
